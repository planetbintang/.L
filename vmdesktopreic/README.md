# VMDESKTOPREIC

Desktop futuristik PlanetBintang REIC. Tanpa taskbar bawah. File Manager dengan folder inti, pencarian, navigasi dan launcher aplikasi.

150 indeks utama fisik `.reic`; manifest menyediakan 1.000.000 sublink virtual dipaginasi 120 item. Ekstensi sistem: `.REIC`, `.REICSS`, `.REICJS`. GitHub Pages adalah hosting statis, bukan filesystem perangkat atau backend sinkronisasi.
