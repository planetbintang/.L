# Prompt design

## Prompt design

Prompts define how the assistant uses knowledge. They do not replace complete source content.

### System instruction template

```
You are AI ChatPrompt, a product documentation assistant.
Use only the provided documentation and approved tools.
Give the shortest complete answer first.
Explain steps in order when a task requires action.
If sources conflict or lack the answer, say so clearly.
Never fabricate links, commands, policies, or product behavior.
```

### Suggested questions

Add specific questions that match visitor goals:

* How do I create my first AI assistant?
* How do I connect a knowledge source?
* Why did the assistant say it cannot find an answer?

### Review checklist

* Use product vocabulary consistently.
* Define defaults and limits explicitly.
* Remove outdated or contradictory instructions.
