# Root `airz/` — Penyimpanan Langsung Sistem Air Cloud

Folder ini adalah tempat sistem Air Cloud menyimpan seluruh struktur file-nya:

- `airsistem/` — sistem folder & file inti (ratusan folder, ribuan file) — setara partisi sistem IBM Cloud.
- `console/` — salinan registry halaman konsol per menu utama.

Akses dari aplikasi: menu **Air Cloud → Penyimpanan Sistem** atau File Manager pada sub URL `#fileManager/airz/airsistem`.
Dibangun oleh `scripts/air_cloud_vfs.py` · 4729 folder terkelola.
