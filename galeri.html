Galeri Gambar

Ruang visual untuk logo, konsep identitas, papan alfabet, dan referensi antarmuka Planetbintang. Pilih gambar dari perangkat untuk menambahkannya ke galeri pada browser ini.

Galeri siap digunakan

Gambar yang dipilih akan tersimpan pada penyimpanan browser di perangkat ini. Agar gambar tersedia untuk semua pengunjung situs, file gambar perlu ikut ditambahkan ke repositori GitHub.

Catatan: penyimpanan gambar yang diimpor bersifat lokal pada browser/perangkat ini dan tidak otomatis mengunggah file ke GitHub.
