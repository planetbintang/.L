# SNAPS Kernel Integration

Status: research and compatibility gate; no REIC kernel is claimed to exist yet.

The first build must use a kernel source tree and configuration proven to match the exact vivo 1904 hardware variant. Record source provenance, license, toolchain, defconfig, compiler version, kernel version, device tree, modules, and vendor interface requirements.

Validate at minimum: boot, display, touch, storage, USB, Wi-Fi, Bluetooth, audio, modem/telephony, camera, sensors, charging, thermal controls, suspend/resume, and emergency-call behavior.

A successful compile is not proof of a usable OS. No kernel should be flashed until a recoverable test path and device-specific review exist.
