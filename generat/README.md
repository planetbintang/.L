# GENERAT — Global PlanetBintang Automation

Central control plane: `planetbintang/.L`, branch `io`. It discovers repositories owned by `planetbintang`, validates change metadata and dispatches notifications. It preserves existing files and never silently overwrites code.

## Setup
Add owner-authorized GitHub Actions secret `PLANETBINTANG_ORG_TOKEN` with repository metadata/content read and repository-dispatch write access for the repositories to monitor. Never place tokens in source files.

The 150 module contracts are generated by `scripts/generate-modules.mjs`; they are distinct responsibility contracts, not filler source. 5,000 meaningful lines per implementation file is a staged quality target, not a reason to generate duplicate or unreachable code.

`REICADMIN` is a logical role label. Actual authority comes from GitHub membership, repository permissions, protected branches and approvals. No unlimited privilege or bypass is created.

New commits are detected and dispatched as `generat.repository.changed`. A target repository must explicitly install and review a receiver workflow before it can apply changes. Untrusted commits are never executed automatically.
