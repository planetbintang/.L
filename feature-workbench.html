Buat / perbarui pekerjaan fitur

Setiap pekerjaan memiliki identitas, tujuan, status, checklist, dan catatan implementasi. Pilih ID katalog jika tersedia atau gunakan ID buatan sendiri.

Checklist verifikasi

Pilih pekerjaan di daftar untuk mengubah checklist. Status “Terverifikasi” memerlukan semua checklist dan URL bukti.

Pilih item pekerjaan dari daftar untuk memeriksa hasilnya.

Ekspor / impor data

Ekspor untuk backup atau pindahkan daftar ke perangkat lain. Impor mengganti data lokal setelah file JSON dipilih.
