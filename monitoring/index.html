Monitoring sistem

Pemeriksaan HTTP langsung untuk halaman dan berkas inti yang diterbitkan di GitHub Pages, dilengkapi umur snapshot repositori yang dipublikasikan.

Memuat daftar route…

Terjangkau—HTTP 2xx
Masalah HTTP—HTTP error / tidak terhubung
Pemeriksaan terakhir—Pembaruan setiap 60 detik saat tab aktif
Batas cakupan

Monitor ini mengecek keterjangkauan URL HTTP dari browser yang sedang membuka halaman. HTTP 200 tidak membuktikan JavaScript aplikasi, database, DNS provider, atau proses backend sehat. GitHub Pages di sini bersifat statis; tidak ada daemon, penyimpanan riwayat terpusat, atau alert server-side. Hasil diperbarui tiap 60 detik hanya selama tab terlihat dan tidak disimpan setelah halaman ditutup.
