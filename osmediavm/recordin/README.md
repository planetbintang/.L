# OS MEDIA VM — Recordin / REIC

Spesifikasi dari tiga folder infrastruktur dikumpulkan ke sini dan diubah dari TXT menjadi REIC.

Runtime statis: index.html, recordin.css, recordin.js, manifest.json. REIC adalah format khusus proyek; browser tidak menjalankannya secara native. Runtime saat ini menampilkan sumber dengan aman sebagai teks. PHP memerlukan server PHP dan tidak berjalan pada GitHub Pages.
