# PlanetBintang GALERI Dashboard

Aplikasi file manager PlanetBintang yang diintegrasikan pada `.L/galeri/dashboard`.

Fitur utama:

- Dashboard GALERI terlindungi login/registrasi.
- Upload langsung ke durable object storage melalui presigned URL.
- Indeks database untuk folder, file, kategori, pencarian, favorit, sharing, dan aktivitas.
- Folder menu All Files, Photos, Videos, Movies, Shared, Favorites, dan Documents.
- Struktur `.L/galeri/dashboard` di dalam aplikasi untuk manifest filesistem virtual.

Jalankan dari folder ini dengan `pnpm install`, `pnpm check`, `pnpm test`, dan `pnpm build`.
