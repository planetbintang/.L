# Katalog repositori Planetbintang

Sumber katalog aktual: [`../../data/repositories.json`](../../data/repositories.json). Cakupan sumber: [`../../data/repository-scope.json`](../../data/repository-scope.json).

Snapshot yang saat ini tercatat meliputi 45 repositori dan metadata sekitar 1.872.594 path. Ini adalah indeks metadata, bukan salinan seluruh isi file. Repositori privat tidak boleh disalin ke area publik tanpa izin, pemeriksaan isi, dan tujuan publikasi yang jelas.

Untuk menjadikan semua file sumber tersedia di satu tempat, gunakan mekanisme mirror terkontrol yang mempertahankan visibilitas setiap repository dan mengecualikan secrets, token, data pengguna, artefak sensitif, serta file yang tidak memiliki izin redistribusi.
