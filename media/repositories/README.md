# Katalog repositori Planetbintang

Manifest pusat: [`index.json`](./index.json). Identitas sistem: [`../planetbintang-system.json`](../planetbintang-system.json). Katalog snapshot File Manager lama: [`../../data/repositories.json`](../../data/repositories.json), dengan cakupan lama di [`../../data/repository-scope.json`](../../data/repository-scope.json).

Manifest pusat dibuat pada 2026-10-29 dan berisi metadata **47 repositori** yang terlihat oleh koneksi GitHub saat dibuat: 41 privat dan 6 publik. Bidang setiap entri mencakup nama, URL GitHub, URL clone, branch default, visibilitas, status arsip, dan ukuran repository yang dilaporkan GitHub.

## Makna indeks

- Manifest adalah snapshot metadata, bukan salinan isi file, blob, atau riwayat commit.
- Repositori sumber tetap menjadi sumber kebenaran dan tidak dipindahkan atau diubah oleh pembuatan indeks ini.
- Tautan privat memerlukan autentikasi dan izin yang sesuai.
- Karena manifest mencantumkan nama repositori privat, jangan terbitkan folder ini di situs publik tanpa peninjauan privasi.
- Daftar dapat menjadi usang; perbarui melalui koneksi GitHub terautentikasi dan catat waktu snapshot. Jangan menyimpan token akses di frontend atau di dalam manifest.

Untuk sinkronisasi file lengkap, gunakan mirror terkontrol yang mempertahankan visibilitas, memeriksa lisensi dan izin, menyaring secrets/data sensitif, serta memiliki mekanisme pembaruan dan audit.
