# Vendor Domain Dashboard — PlanetBintang .L

Dashboard statis berbahasa Indonesia untuk pengelolaan domain, vendor, ekstensi, DNS, penerbitan teks, hosting, API, dan konfigurasi sistem.

## Isi
- 1 menu utama di header: **Vendor Domain**
- 4 kelompok dropdown header: Vendor Domain, Domain & Ekstensi, Publikasi & Developer, Vendor & Sistem
- 20 modul × 25 fitur = **500 fitur**
- Setiap blok fitur memiliki 15 aksi kontekstual = **7.500 aksi**
- Pencarian, filter modul, favorit, blok aksi, ekspor katalog JSON
- Konversi teks menjadi HTML statis, pratinjau kode, unduh HTML, simpan draf lokal
- Checklist penerbitan domain, DNS, hosting, dan HTTPS
- Responsif untuk desktop dan ponsel, navigasi keyboard dan atribut aksesibilitas

## Buka
Buka `index.html` secara langsung atau publikasikan direktori `vendordomain/` melalui GitHub Pages.

## Batas integrasi
Katalog dan aksi demo berjalan di browser dan menyimpan preferensi/draf pada localStorage. Pendaftaran domain, operasi registrar, perubahan DNS publik, pembayaran, penerbitan sertifikat, deployment server, dan analitik produksi membutuhkan backend serta kredensial API penyedia yang sah. Halaman ini tidak mengklaim layanan eksternal telah aktif.
