LIVE PROVIDER INTEGRATION

DNS Manager

Baca, buat, dan hapus record DNS melalui backend Cloudflare yang terautentikasi.

DNS live membutuhkan backend HTTPS dengan CLOUDFLARE_API_TOKEN dan CLOUDFLARE_ZONE_ID pada server. Tidak ada secret yang disimpan di frontend.

Buat record DNS

Validasi sebelum perubahan

  • Pastikan zone ID dan zona domain benar pada server.
  • Token Cloudflare hanya boleh berada pada environment server.
  • Perubahan DNS bersifat nyata dan dapat memengaruhi situs/email.
  • Hapus record memerlukan konfirmasi eksplisit.

DOMAIN TOOLKIT

Validasi domain

Memeriksa sintaks nama domain. Ini bukan pemeriksaan ketersediaan registrar atau pembelian domain.

Catatan pemeriksaan

Pemeriksaan sintaks dapat dilakukan tanpa API. Status registrar, transfer, renewal, dan pembayaran memerlukan integrasi registrar resmi serta backend yang sesuai.

AUDIT TRAIL

Audit aktivitas

Peristiwa dari backend ditampilkan ketika API terhubung; mode lokal memiliki riwayat terpisah.

SYSTEM CONFIGURATION

Konfigurasi sistem

Hubungkan aplikasi ke backend VendorDomain. URL disimpan pada browser; token hanya di memori sesi tab.

Status integrasi

Backend belum diperiksa.
Keamanan: jangan masukkan token produksi pada browser/perangkat yang tidak tepercaya. Untuk produksi, letakkan autentikasi di server-side session/proxy, aktifkan HTTPS dan batasi origin. Token tidak pernah disisipkan ke source code.

Kapabilitas dan batas integrasi

  • CRUD data modul, validasi sintaks domain, ekspor/impor JSON: tersedia.
  • Record DNS Cloudflare: memerlukan backend hidup dan kredensial zone di environment server.
  • Pendaftaran domain, transfer, renewal, invoice/payment, hosting dan email: memerlukan API provider/kontrak serta implementasi server terpisah; tidak dianggap aktif hanya karena modul tampil.
  • GitHub Pages hanya melayani frontend statis, bukan menjalankan Node.js backend.
