# Konfigurasi Pengguna, Tim dan Akses

Konfigurasi terpisah untuk 25 menu VendorDomain modul 17. Setiap menu memiliki enam lapisan: Layout, Pilihan, Penerapan, Penyimpanan, Penyimpanan Sistem Folder File, dan Konfigurasi. Manifest `pengguna-tim-akses.json` menyimpan profil unik per menu. UI menyediakan pratinjau, penerapan lokal, simpan, impor, dan ekspor JSON.

Catatan: GitHub Pages adalah hosting statis; penyimpanan konfigurasi UI berjalan di browser/perangkat, bukan backend autentikasi produksi.
