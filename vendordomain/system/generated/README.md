# VendorDomain — Filesystem Sistem Modular

Direktori ini berisi 510 folder modul dan 1.530 file modul (`module.json`, `README.md`, `index.js` per folder), ditambah manifest dan README akar.

Modul mencakup dasbor, admin, member, user, domain, DNS, hosting, billing, keamanan, konfigurasi, manajer file, API, laporan, konten, dukungan, monitoring, backup, workflow, database, dan sistem.

**Status:** scaffold fungsional untuk metadata dan validasi input; data bersifat demo/local. Bukan backend produksi. Sebelum produksi, tambahkan autentikasi sisi server, otorisasi peran, penyimpanan persisten, audit, proteksi CSRF, rate limiting, dan integrasi registrar/DNS yang sah. Jangan simpan rahasia di frontend.
